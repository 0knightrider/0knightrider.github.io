Live Oceanographic Sensor Dashboard

R/V F.G. Walton Smith

Real-time vessel telemetry and CTD cast visualization suite that parses binary navigation and heading packets alongside live CSV sensor feeds into interactive depth, salinity, and temperature profiles.

  • Multi-tab Gradio interface with a dedicated CTD cast viewer.
  • Python
  • Gradio
  • Matplotlib
  • Binary Parsing
02Research

Spinal Cord Injury Gait Recovery Pipeline

Ali Lab · University of Miami

Reproducible statistical analysis and visualization pipeline that quantifies locomotor recovery in preclinical models from gait kinematics, giving the lab an objective measure of how far treatment restores healthy walking.

How it works
  • Scores recovery as Mahalanobis distance from the healthy baseline.
  • Non-parametric permutation testing for group comparisons.
  • Handles baseline-only, single-treatment, and multi-treatment designs.
  • Python
  • NumPy
  • Pandas
  • SciPy
  • Statistical Modeling
